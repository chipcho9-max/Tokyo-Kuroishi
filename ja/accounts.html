口座と税金

まず非課税の枠から埋める

30年で見ると、投資の中身と同じくらい「どの口座で持つか」が結果を左右します。ここで 扱う3カ国はどれも、複利の一部または全部を非課税で走らせられる、政府が設計した合法的な 枠を用意しています。普通の課税口座に1円を入れる前にそれらを使い切ることは、あなたが 手にできる「タダのリターン」に最も近いものです。

数字と日付は動きます。 以下の拠出上限・税率・制度は2026年初時点の 情報を教育用に簡略化したものです。3カ国とも、ほぼ毎年の予算・税制改正で変わります。 実行前に必ず公式情報(IRS、国税庁/金融庁、국세청/금융위원회)か資格ある専門家に 確認してください。
米国

401(k)、IRA、そして長期キャピタルゲインの優遇

口座年間上限(2025年)税制長期投資家へのメモ
401(k) / 403(b) $23,500(本人拠出) Traditional:拠出時控除・引出時課税。Roth:拠出時課税・引出時非課税。 まず雇用主マッチを満額取ること — どんな市場も提供できない、即時の確定リターンです。
IRA / Roth IRA $7,000 Roth:税引後拠出、運用益も引出も老後は非課税(所得制限あり)。 数十年の複利が丸ごと非課税になるRothは若い人ほど強力。拠出元本(利益は除く)はいつでも引出可能。
HSA $4,300(単身) 高免責額の医療保険とセットで三重優遇:拠出控除・運用非課税・医療目的の引出非課税。 運用に回したHSA残高は、対象者にとって隠れた老後資金口座です。
課税口座(証券口座) 無制限 1年超保有の長期キャピタルゲイン:所得に応じ0% / 15% / 20%。適格配当も同率。 数十年の保有は課税を無期限に繰り延べます。現行法では相続時に取得価額のステップアップも。インデックスファンドは構造的に税効率が高い。

米国居住者の優先順位(一般的なデフォルト)

  1. 401(k)を雇用主マッチ満額まで。
  2. 高金利の借金完済、現金の生活防衛資金。
  3. RothまたはTraditional IRAを上限まで。
  4. 対象ならHSAを上限まで。
  5. 401(k)の残り枠を上限まで。
  6. 課税口座で広範なインデックスファンド。1年超、できれば数十年保有。
日本

新NISA:数十年スケールの贈り物

2024年に生まれ変わったNISAは、世界でも有数の寛大な個人向け非課税制度です。枠内では 譲渡益も配当も無期限で非課税 — 通常口座の20.315%課税と比べてください。 米国・全世界インデックスファンドを20〜30年複利で回す日本の居住者にとって、NISAを 最初に埋めるのはほぼ自明の一手です。

NISAをもっと詳しく。 2つの枠の違い、生涯1,800万円が簿価で数えられる仕組み、 よくある誤解、そして知らないと損をする手続きの落とし穴まで — NISA徹底ガイドにまとめました。
制度年間枠生涯枠メモ
NISA つみたて投資枠 120万円 合計1,800万円
(うち成長投資枠は最大1,200万円)		 承認された低コスト投信の積立購入 — 承認リストはS&P 500と全世界(オルカン)型が中心。積立投資のために設計された枠です。
NISA 成長投資枠 240万円 上場株式・ETFを含む広いメニュー。売却すると翌年に生涯枠が復活 — 枠は再利用できます。
iDeCo 約14.4万〜81.6万円
(働き方で異なる)		 — 個人型確定拠出年金:掛金は全額所得控除、運用益非課税、ただし60歳まで引出不可。安定収入がある人には所得控除が非常に強力。
特定口座(課税) 無制限 — 譲渡益・配当に一律20.315%。源泉徴収と申告は証券会社が処理。NISAとiDeCoを使い切った後の受け皿です。
日本から米国株を持つ場合: 日米租税条約により、米国は配当の10%を源泉 徴収します(証券会社経由でW-8BENを提出)。課税口座では日本側でも課税され、確定申告で 外国税額控除が使えます。NISA内では日本側の税は消えますが、米国の10%源泉徴収は 残ります — 配当の少ない広範なインデックスファンドがNISAに特に合う理由の一つです。 S&P 500連動の円建て投信なら、この配管をすべてファンド内部で処理してくれます。

日本居住者の優先順位(一般的なデフォルト)

  1. 円預金で生活防衛資金。
  2. NISAつみたて投資枠で低コストのS&P 500/オルカン投信を毎月自動積立。
  3. 所得控除が効き、60歳ロックを許容できるならiDeCo。
  4. NISA成長投資枠で年間合計360万円へ。
  5. それ以上は特定口座で。
韓国

연금저축・IRP・ISA — そして22%の海外株譲渡益課税

米国上場株を直接持つ韓国の投資家には、独特の税制があります:海外上場株の 譲渡益は、年間250万ウォンの基礎控除を超えた純利益に22%課税(地方税込み)。 毎年5月に自己申告し、同一年内の損失は利益と相殺できます。米国配当は条約により15%が 源泉徴収され、金融所得が大きいと総合課税の対象になります。下の優遇口座は 韓国上場のETFを保有できます — 米国指数連動の韓国上場ETFを通じて、多くの 長期投資家が税制優遇付きのS&P 500エクスポージャーを得ています。

口座拠出税制優遇長期投資家へのメモ
연금저축펀드
(年金貯蓄ファンド)		 年1,800万₩まで
(IRPと合算)		 600万₩まで13.2〜16.5%の税額控除(IRP合算で900万₩)。運用益は課税繰延、年金受取時は3.3〜5.5%。 韓国上場のS&P 500/ナスダック/全世界ETFを保有可能。毎年の税額控除付きの、韓国版・数十年非課税枠に最も近い存在。
IRP(個人型退職年金) 上の1,800万₩を共有 연금저축と同じ控除枠で合計900万₩まで。30%以上は低リスク資産に置く義務。 연금저축の後に追加300万₩の控除を取るために。55歳まで原則ロック。
ISA(중개형) 年2,000万₩、累計1億₩ 利益200万₩(低所得者は400万₩)まで非課税、超過分は9.9%の分離課税。最低3年保有。 韓国上場の株式・ETFを保有(海外上場は直接不可)。満期資金を연금저축に移すと追加の税額控除 — 忍耐強い人のためのリレーです。
海外株口座(課税) 無制限 年250万₩超の譲渡益に22%。米国配当は15%源泉徴収。 米国上場の株式・ETFを直接保有。年250万₩の控除は、計画的に少しずつ利益確定する人に報います。
韓国上場か米国上場か: 同じS&P 500でも、ファンドの上場地で課税が 変わります — 課税口座の韓国上場・海外指数ETFは配当所得として15.4%(総合課税の閾値にも 算入)、米国上場は22%/250万₩控除の譲渡益課税。どちらが得かは金額と他の所得次第です。 연금저축/IRP/ISAの中ではこの問題がほぼ消えます — まずそちらを埋めるべきもう一つの 理由です。

韓国居住者の優先順位(一般的なデフォルト)

  1. ウォン預金で生活防衛資金。
  2. 연금저축펀드に年600万₩(税額控除満額)、広範なインデックスETFを毎月自動積立。
  3. 追加控除と55歳ロックが合うならIRPで合計900万₩へ。
  4. ISA(중개형)を年間枠へ。
  5. 課税口座 — 上の税制メモを踏まえて韓国上場か米国上場を選ぶ。
国境を越える細則

米国株を持つ非米国居住者が知るべき3つのこと

1. 配当の源泉徴収

米国は配当があなたに届く前に課税します:租税条約により日本の居住者は10%、 韓国の居住者は15% — 証券会社に有効なW-8BENが提出されて いることを確認してください。なければデフォルトの30%です。母国側でも課税され、 申告時に外国税額控除が使えます。一方キャピタルゲインは、条約国の居住者には 米国側では原則課税されません — 母国でのみ課税されます。

2. 米国の相続税(遺産税)

非居住外国人の米国内資産(米国上場株を含む)には、わずか6万ドルの控除を 超えると最大40%の米国遺産税がかかり得ます。日本は日米相続税条約により実効的な控除を 大きく引き上げられますが、韓国には条約がありません。大きな ポートフォリオでは現実の問題です — 非米国籍(アイルランド上場UCITSなど)のファンドを 使う非米国投資家がいる理由の一つでもあります。重要になる前に、クロスボーダーの 専門家に相談を。

3. 為替とコスト

売買時の為替手数料は現実のコストで — ファンドの信託報酬より大きいことも多く — 証券会社によって大きく異なります。米国株を保有する母国上場ファンド(東京上場の S&P 500投信、韓国上場のS&P 500 ETF)は、為替処理をファンド内部の機関投資家 レートに押し込み、優遇口座にも収まります。ヘッジの有無は市場ページの為替の節へ。
